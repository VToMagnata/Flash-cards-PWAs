
# 📚 Flash Cards

Aplicação web de Flash Cards desenvolvida para auxiliar nos estudos e na memorização de conteúdos por meio de cartões com perguntas e respostas.

## 🚀 Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React

## 📌 Sobre o projeto

O Flash Cards é uma aplicação que permite criar cartões de estudo contendo perguntas e respostas.

O projeto foi desenvolvido com foco na prática de desenvolvimento frontend, componentização, gerenciamento de estado com React e construção de interfaces responsivas utilizando Tailwind CSS.

## ✨ Funcionalidades

- [x] Criar Flash Cards
- [x] Adicionar perguntas e respostas
- [x] Visualizar cartões de estudo
- [x] Interface responsiva
- [x] Componentização com React

## 🛠️ Como executar o projeto

### 1. Clone o repositório

```bash
git clone URL_DO_SEU_REPOSITORIO
```

### 2. Acesse a pasta

```bash
cd flash-cards
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

Acesse no navegador:

http://localhost:3000
